# NULL NETWORK

NULL NETWORK is being rebuilt from scratch in Godot 4.6.

## Branches

- `main`: active reboot, implemented incrementally by the project author
- `legacy`: archived previous implementation, including its historical code, scenes, assets, and documentation

The old implementation is available for reference, but its architecture and files are not assumed to exist in the reboot.

## Development approach

The project author writes, tests, and owns the code. AI may assist with Godot concepts, design discussions, architecture review, and debugging, but should not generate complete implementations by default.

Canonical gameplay design remains valid unless explicitly revised. The new Godot project and technical structure will be created incrementally.
